MCE Mac

個人用のGmail自動分類ツール / Personal Gmail labeling tool

MCE Mac は、開発者本人が自分のGmailの受信メールにラベルを付けて整理するためだけに使う、個人用のツールです。一般には公開・配布していません。

メールの処理は、開発者が所有するコンピュータの中だけで行います。メールの送信や削除は行いません。

MCE Mac is a personal tool used only by its developer to label and organize messages in the developer's own Gmail account. It is not distributed to the public. Processing happens only on the developer's own computer; the tool never sends or deletes email.
