MCE Mac プライバシーポリシー

制定日：2026年11月20日

1. 対象

MCE Mac（以下「本ツール」）は、開発者本人のGmailアカウントだけを対象とする個人用ツールです。開発者以外の利用者はいません。

2. 取得する情報

本ツールは、Gmail API（スコープ：gmail.modify）を通じて、次の情報を読み取ります。

  • メールのヘッダー（差出人、宛先、件名など）と、付いているラベル
  • 分類の判断に必要な場合に限り、本文の冒頭部分

3. 利用目的

取得した情報は、メールにラベルを付けて整理する目的にだけ使います。本ツールが行う操作は、ラベルの追加・削除（受信トレイからのアーカイブを含む）だけです。メールの送信、削除、ゴミ箱への移動は行いません。

4. 保存と第三者提供

  • 処理は、開発者が所有するコンピュータの中だけで行います。
  • メール本文は保存しません。分類の記録（差出人・宛先・件名・付けたラベル）だけを、暗号化されたディスク上に一定期間保存します。
  • 取得した情報を、第三者に提供・販売することはありません。外部のAIサービスにメールの内容を送ることもありません。
  • Gmail APIから受け取った情報の取り扱いは、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

5. アクセスの取り消し

Googleアカウントの「サードパーティ製のアプリとサービス」から、本ツールのアクセスをいつでも取り消せます。

Privacy Policy (English summary)

MCE Mac is a personal tool used only by its developer, for the developer's own Gmail account. Using the Gmail API (gmail.modify scope), it reads message headers, labels and, when needed, the beginning of the message body, solely to apply labels (including archiving). It never sends, deletes or trashes email. All processing happens on the developer's own computer; message bodies are not stored, and no data is shared with or sold to third parties or sent to external AI services. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account's third-party apps settings.
